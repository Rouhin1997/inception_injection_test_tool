## INCEPTION-Lite (personal development branch)

A lightweight, Nextflow-free Python front end for reproducible single-source,
multiple-source, grid, and random pulsar injections is available on
the [dev/pulsejet-injections](https://github.com/Rouhin1997/inception_injection_test_tool/tree/dev/pulsejet-injections)
branch. Read [INCEPTION_LITE.md](INCEPTION_LITE.md) for configuration,
physical conventions, injected-signal verification, optional PulsarX folding,
and generic SLURM/SingularityCE deployment.

The original INCEPTION injection physics and MPIfR validator remain included
unchanged for comparison.
